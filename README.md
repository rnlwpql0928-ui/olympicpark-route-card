# 공연별 다국어 동선 카드 (시연)

올림픽공원 공연이 끝난 밤, 가는 곳을 고르면 「공연장 안내에 적힌 역」과 「공연 밤에 덜 붐볐던 역」을 나란히 놓고 역마다 걷는 시간, 공연 밤 승차 배수, 늦어도 나설 시각을 한국어·영어·중국어·일본어 카드 한 장으로 보여 주는 정적 웹 시연입니다.

- 카드: https://rnlwpql0928-ui.github.io/olympicpark-route-card/
- 운영 점검표: https://rnlwpql0928-ui.github.io/olympicpark-route-card/ops.html

## 자료

화면의 자료 출처 칸에 적힌 것과 같습니다.

- 공연 회차: 주최 올림픽공원 공연정보 · 공연 길이: 대관정보(공공데이터포털 15015212), 주최 주차 안내 화면
- 역별 승차: 서울교통공사 역별 일별 시간대별 승하차인원 2024·2025(서울 열린데이터광장 OA-12921), 9호선 2·3단계(OA-22441)
- 열차 시각·정차 순서: 서울교통공사 서울 도시철도 열차운행시각표(15098251) · 갈아타는 시간: 환승역거리 소요시간 정보(15044419)
- 역 이름 표기: 서울교통공사 역명다국어표기(15044232)
- 출구·공원 이용 시간: 주최 공연장 안내·「오시는 길」·공원 이용 안내

`data/` 의 파일은 계산 도구가 위 공개 자료에서 만든 결과입니다. 열차 시각은 바뀔 수 있으니 타기 전에 역 안내를 확인하세요.
